VEILFORGE v3.2 FINAL — MAIN BRANCH GITHUB UPLOAD

1. Extract this ZIP on your computer.
2. Open the extracted folder.
3. Select every file and folder inside it. Do not upload the ZIP file itself.
4. In the GitHub repository, open Add file > Upload files.
5. Drag all selected files and folders into the upload area.
6. Choose the main branch and commit the files directly to main.
7. Wait for Vercel to build the project and finish the production deployment.

Vercel settings are already included:
- Build command: npm run build:web
- Output directory: dist
- Node.js: 20 or newer

The ZIP itself must not be uploaded as one file because GitHub does not automatically extract ZIP archives.
