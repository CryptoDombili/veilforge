# Privacy Operating System modules

## Genome

Builds a source-derived registry of protected assets, actors, graph nodes, graph edges and actor-to-asset visibility states.

## Intent

Produces a deterministic policy document and reports mismatches between protected-data intent and current code behavior.

## Shadow Lab

Converts findings into adversarial evidence campaigns. Each campaign is bound to exact source evidence and exposes its limitations.

## Transaction MRI

Creates an ordered source-level disclosure narrative: call surface, storage/function/event/selector evidence and policy boundary.

## Forge

Produces candidate hardening edits for narrow transformations and refuses unsafe generic mutation.

## Passport

Creates a source-bound identity containing privacy pillars, evidence counts, gate state and explicit claims.
